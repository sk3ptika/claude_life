### Optional: Google Apps Script Web App für automatischen 2-Wege-Sync

Um Änderungen aus dem Google Sheet mobil ohne manuellen Export abzugleichen, kann im Google Sheet unter *Erweiterungen -> Apps Script* folgendes kurzes Skript hinterlegt und als Web-App bereitgestellt werden:

```javascript
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var body = JSON.parse(e.postData.contents);
  if (body.rows) {
    sheet.clear();
    sheet.getRange(1, 1, body.rows.length, body.rows[0].length).setValues(body.rows);
  }
  return ContentService.createTextOutput(JSON.stringify({status: "ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
```
Die erhaltene Web-App-URL kann im Frontmatter unter `gsheet_sync_url: <url>` eingetragen werden.
